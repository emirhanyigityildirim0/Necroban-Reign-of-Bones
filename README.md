## 📜 About the Game
**Necroban: Reign of Bones** is a dark fantasy 2D action-platformer with Souls-like mechanics, currently under development with Godot Engine 4.

The Necromancer has conquered all races—goblins, dwarves, elves—and transformed the world into a "Reign of Bones." As **The Last Mortal**, you must ascend from the deepest, darkest caves and put an end to this eternal curse.

## ⚔️ Key Features
* **Smart Enemy AI:** Skeletons that patrol, chase on sight, and refuse to fall off cliffs.
* **Dynamic Combat System:** Visceral combat with camera shake on impact and custom collision handling to prevent "corpse soccer" (enemies become non-collidable upon death).
* **Atmospheric World:** Pitch-black cave systems illuminated by dynamic 2D lighting and torches (`CanvasModulate`).
* **Dark Narrative:** The desperate ascent of humanity's last remnant against a horde of undead.

## 🛠️ Tech Stack
* **Engine:** Godot Engine 4.x
* **Language:** GDScript
* **Graphics:** Pixel Art / 2D Assets
* **Platform:** PC (Windows/Linux)
